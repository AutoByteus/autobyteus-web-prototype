# App Review Information — notes draft (autobyteus-279)

Status: **draft for the founder's approval**. Nothing goes to App Store Connect, TestFlight or the App Review thread without his explicit word.

## Notes (paste into App Store Connect › App Review Information › Notes)

> AutoByteus Mobile is the phone and tablet companion of AutoByteus, an app people run on their own computer to work with AI agents. Normally the app connects to the user's own computer by scanning a QR code that the computer shows.
>
> For review, the app has a built-in demo with sample data. No account, computer, network setup or QR code from a computer is needed, and nothing is sent anywhere.
>
> To open the demo, either:
> 1. On the first screen, tap **Try demo**, or
> 2. Tap **Scan** and point the camera at the attached demo QR code (it also opens from the iPhone or iPad Camera app).
>
> In the demo you can try every feature of the app:
> - The run list: agents, Teams and an Org with their work, and runs that are working, idle or stopped.
> - Open a run to read its conversation, with tool calls, a terminal, file edits, a formatted answer, an image and a message from another agent.
> - Send a message: the agent answers with a sample reply. Stop a working agent with the red stop button.
> - The ⋮ menu of a run: Artifacts, Files, Messages (a Team or Org member), Activity (background tasks and tool calls), Settings (runtime and model), VNC Viewer (a view-only sample desktop), and Text size.
> - Start a new run with the + button.
> - The demo's name at the top left opens "Leave demo", which returns to the first screen.
>
> On iPad in landscape, the run list and the open run show side by side.

Attachment: `autobyteus-demo-qr-card.png` (the demo QR code with a caption). The plain code is `autobyteus-demo-qr.png`; it holds `autobyteus://demo`.

## Round 3 — a design for each network type (private-network-types.md, Solution Designer 2026-11-24)

| ID | Change | Source |
| --- | --- | --- |
| DC-029 | Joining offers three types as radio cards: **Tailscale account**, **My own Headscale server** (yours, your team's, or one hosted on another of your machines), **Host a private network on this machine**. Each has its own join step. | types 1–3 |
| DC-030 | Tailscale: Sign in, or an auth key with "make a one-time key without tags… a tagged machine belongs to the tag". States **Waiting for approval in your Tailscale admin console** (device approval; the page continues by itself) and **Signed out of Tailscale … Sign in again** (key expiry; advice to turn off key expiry). My machines shows a tagged machine (`tag:ci`, never yours) and a machine **shared with you** (someone else's). | type 1 b, c, e |
| DC-031 | Headscale: server URL + join key, or **I have an invite link** (made on a host). Add a machine: paste a key from `headscale preauthkeys create --user alex --expiration 10m`, or **Let this node make keys itself** by storing a Headscale API key (password field; kept in the node's vault, never shown again; then Add a machine is one click). **Server unreachable**: the card and the page say nobody can join or change anything and existing connections keep working for a while. | type 2 b, d, e |
| DC-032 | Host a private network: warning (always-on machine, a laptop is a poor host, off = nobody can join), domain + HTTPS port, "Before you start" (DNS, router port forward, only that port is public), the steps Start the network server · Get a certificate · Check it is reachable from the internet · Join this machine to its own network, a failed reachability check with **Check again**. Joined: **Hosting** (address, certificate valid until …, reachable from the internet + Check again), **Add a machine** in one click, **Invite someone** (invite link + QR, 24 hours, works once). | type 3 |
| DC-033 | **Your own VPN** section on the Private Network page in every state: accepted ranges as chips with Remove, Accept range (refuses ranges larger than /16), the warning "every machine in the range can reach this node's sign-in; its data still needs a credential". Usable alone or with types 1–3; alone, the card is On ("Accepting your own VPN: … Not on a private network."). | type 4 |
| DC-034 | Manage Nodes card by mode: **found** (joined; the lead names the network: "Tailscale · alex@example.com", "Headscale · headscale.example.com", "hosted on this machine · net.example.com"; with a VPN range a second line says those nodes are added by address); **own VPN only** ("cannot find nodes or tell who is calling. | DC-035 | **Leave this private network** (or, hosting, **Stop hosting and end this private network**) with an inline confirmation: switching means leaving, joining the new one and pairing again; old pairings stay but cannot reach (hosting: every machine loses the network). | g |
| DC-036 | The catalog description names all four ways; account names follow the network (Tailscale logins; Headscale user names). | — |

Validated: joining a Headscale server with URL + key, machine list, who-is, pairing, the connection code. Not designed: NetBird, the AutoByteus-hosted network.
